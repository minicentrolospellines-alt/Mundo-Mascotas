# Validación v1.0

- Sintaxis JavaScript verificada con Node.
- Pruebas de reglas aprobadas: compras, saldo, alimentación, recompensa máxima, reducción de necesidades y recuperación de datos.
- Generación de siete pantallas y sintaxis de sus controles comprobadas; compra y colocación de una casa verificadas con guardado. XML Android verificado.
- No fue posible comprobar visualmente en navegador: este entorno no dispone del ejecutable Chromium.
- La compilación Android no se ha ejecutado en este entorno. GitHub Actions incluye las pruebas y generará el APK de prueba y AAB sin firma.
- Antes de distribuir, probar los cuatro minijuegos y el guardado en un teléfono Android.
